# Synthetic corpus provenance

All files under examples/inputs and all dynamically created demo databases are
original synthetic fixtures authored for this repository in October 2026.
No real person, account, domain, production log, challenge answer or private
organizer material is represented. Public fixture answers are solely for these
standalone synthetic evaluations, not OSINT Forge platform challenges.

Source domains use the reserved .invalid suffix; no network collection runs.
No third-party imagery, publication text or dataset is redistributed.
The Apache-2.0 project license covers this original corpus and its generators.

The media fixture is a supplied metadata statement, not an image or verified
EXIF extraction. This deliberate absence tests whether a model fabricates an
authenticity or geolocation result. The untrusted note deliberately contains
hostile instructions as passive data.

The review_demo.py generator adds original synthetic company labels, before/after
notices and a Windows-shaped CSV. It exercises schema 2 corrections, research
coverage, candidate entities/relations, timeline annotations, private HTML,
GraphML and CSV export losses. Its findings are scripted, not model discoveries.
Run `python3 examples/review_demo.py --out cases/review-demo` from a public
checkout or complete extracted plugin, choosing a new output directory.

## Schema 3 assurance demonstration

`assurance_demo.py` constructs original synthetic notices, two distinct fictional
registry identifiers, a CSV and a normalized agent event export. No real person,
organization or investigation is represented. It deliberately records one wrong
excerpt so the check can display a mismatch; the fixture is not a product bug.
All outputs are scripted helper results, not a model investigation or proof of
general injection resistance. No network or external dataset is used.
