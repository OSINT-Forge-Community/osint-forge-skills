The banners, mascots and other local visual assets in this project are the

Apache-2.0 license covering the software, skill instructions and textual documentation.
Reuse, modification or redistribution of these visual assets requires prior
written authorization from OSINT Forge. See the [visual asset notice](../../assets/LICENSE.txt).

Silex, the lynx, and Rivet, the automaton, are the project's promotional mascots.
The illustrations are synthetic artwork, not investigation evidence.

Both banners measure 2170 × 725 pixels and are stored locally.

The README uses standard [Shields.io badges](https://shields.io/badges/static-badge)
embedded with HTML links and images. Their remote images display package
version, skill count, optional tools, Python requirements and software license.
They are not OSINT Forge artwork or part of the offline Python runtime.
The local investigation workflow retains its original SVG design. Badge labels
use title case, with charcoal backgrounds and muted copper, slate and blue accents.

Generation prompts, creative briefs and source references remain private.

The research and toolkit diagrams are original static SVGs with accessible titles
and descriptions. They explain data flow and capability boundaries; they contain
no external fonts, scripts, remote resources or performance statistics.
