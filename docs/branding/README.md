# README visual identity

The main banner follows the maintainer's OSINT Forge banner direction of
2026-10-13: calm obsidian, ivory headline on the left, faceted matte characters
on the right, low-contrast geometric background and restrained copper accents.

The selected mascots are **Silex, the lynx**, and **Rivet, the automaton**. Their
roles are editorial metaphors for observation and construction, not claims
about software features. The duo is promotional artwork, never case evidence.
The existing OSINT Forge logo is not replaced or modified.

The reference documents were the brand's GRAPHISM.md and design/banners.md,
with the original silex.png and rivet.png concepts. No application code, private
challenge content, account information or production data was used.

## Assets

- [English README banner](../../assets/readme-banner.en.png): revision 3, localized
  on 2026-10-14 with the built-in imagegen tool. The English lettering reads
  "AI Skills" and "OSINT · Forensics · Evidence".
- [French README banner](../../assets/readme-banner.png): retained revision 2,
  generated from the two existing mascot references and used by README.fr.md.
- [Asset provenance](provenance.json): actual dimensions, hashes and purpose.
- [Local badges](../../assets/badges/): original SVG source using the brand
  palette and system monospace fonts. No badge provider, script or font fetch.

Both banners are 2170 x 725 px, approximately 3:1. Its lettering is generated and
approximates the brand typography; it is not a verified Space Grotesk/Inter font
composition. Essential project information also appears as ordinary README text.

The creative generation environment is external and is not classified as
sovereign. Distribution uses a local PNG with no runtime image-generation API,
SDK, model dependency or telemetry. The image does not authorize a new provider
integration. There was no automatic publication.

Only the retained output is included in the project. Source references and
creation-cache paths are not copied into the public product. No privacy claim
or copyright certification is inferred from image generation.
