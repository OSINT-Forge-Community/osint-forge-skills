## 0.1.4 - 2026-10-14

Local package version alignment; no tag or publication is implied.

- Reduced both README editions by about half, added colored local SVG workflow
  diagrams and badges, and moved detailed validation notes into disclosures.
- Synchronized package, marketplace, skill and runtime version metadata at 0.1.4.
  Historical benchmark and compatibility observations retain their original scope.

- Published contribution guidance for GitHub feedback, bugs and suggestions,
  with issue labels and separate security and personal-data email contacts.
  Included the public guide in the full plugin; maintainer notes remain local.

- Added optional local adapters for ExifTool, ffprobe, Poppler pdftotext and
  Tesseract, with explicit executable selection, evidence copies, bounded
  execution and provenance-bearing analyses. No third-party binary is bundled
  or installed. Synthetic adapter tests are distinct from real-binary trials.
- Added host-tool workflows for authorized public-source, DNS/RDAP and map
  research. Updated five skills and both README editions with tool capabilities,
  prerequisites and integration-test limits. Python helpers make no web lookup.

- Preserved source row index `0` in timeline CSV exports after chronological
  sorting, while retaining empty missing timestamps and spreadsheet formula
  neutralization. Original evidence and JSON analyses remain unchanged.

- Clarified OSINT Forge ownership and reserved rights for visual assets,
  separately from the Apache-2.0 software license. Kept creative direction
  and source references local; public provenance retains output metadata.
- Refined the README benchmark summary around reproducible checks and linked
  the exploratory agent comparison without implying a demonstrated skill gain.

- Removed explanatory source comments and docstrings while preserving CLI help
  and executable directives; regenerated packages and reran the offline benchmark.
- Recorded a six-session Codex SkillsBench citation-check pilot: 3/3 passed in
  each arm, with no observed explicit skill reads and no demonstrated accuracy gain.
  Published minimized results, frozen input hashes and the optional evaluation adapter.

- Simplified both README editions with a shared investigation diagram, synthetic
  report preview, short demo and skills grouped by stage. Detailed measurements
  now live in the benchmark guide; installation links lead to client sections.

- Bounded browser SQLite values and cumulative output before materialization;
  preserved exact URLs and excluded legacy clipped URLs from equality matches.
- Corrected fractional-second ordering and retained unrepresentable UTC dates
  as invalid events. Preserved full accepted scope and rationale in reports.
- Recognized Markdown-escaped credential keys during sharing preparation and
  public-export checks.
- Added explicit `add-many` intake with a case lock and full verification before
  and after the batch, reducing repeated raw reads. Partial completion is explicit.
- Added a public, offline synthetic benchmark runner, measured results and
  a sourced guide for evaluating skills with external benchmarks.
- English is now the primary README and user documentation language, including
  navigation, walkthrough commands, examples and skill discovery descriptions.
- Preserved the full French overview in README.fr.md; README.en.md redirects
  readers to the main English README. Existing guide paths remain stable.
- Added an English banner and translated the local license badge; generated
  distribution READMEs use the English banner. Both banner variants have provenance.
- English remains the default report language; optional French labels are retained.
