# Investigate domain infrastructure notes

The package makes no DNS, RDAP, certificate-transparency or HTTP collection. It interprets captures and guides already authorized host capabilities. A URL is not permission for active reconnaissance.

Registrar, nameserver operator, CDN and host are distinct roles. Registration, certificate issuance and connectivity prove different things. A shared IP or certificate service is not shared ownership.

Historical observations can survive migrations. TTL is not a creation date. Interpret RDAP event dates by their event action rather than calling every update a transfer.

The demo uses reserved .invalid domains and stored JSON. Never query production OSINT Forge domains. Prepare a bounded operator request when production evidence is missing.

## Qualify the supplied observation

A useful capture states the exact selector, record type, registry/resolver,
observation time, response and truncation/access limits. Distinguish a query to
a third-party index from a direct TLS/HTTP connection to the target. A provider's
"passive" label does not establish that distinction. Use the source card's RDAP
reference to find authoritative guidance; no endpoint is invented or called by
the runtime. Record historical roles and current observations separately.
