# Start an investigation notes

Capture the question, subjects, output audience, time window, available pieces and permitted collection. A request to explain a method does not authorize live collection. Supplied exports are sufficient for an offline first pass.

Maintain supported observations separately from questions requiring evidence. Identify the smallest observation that distinguishes the leading explanations. An unsuccessful search is a coverage gap unless detectability and coverage justify a negative finding.

The operator supplies stable copies. Request a coherent browser backup rather than scanning live profiles. Production evidence comes through minimized operator exports; agents do not operate OSINT Forge production.

Resume a case by checking integrity and its original scope. Additional evidence never silently expands permission.

For a bounded, explicitly selected list, `add-many` verifies the case before and after intake under one lock. It never crawls directories. Optional provenance applies to every selected file. A failure may leave completed additions: verify the case and inspect its journal before resuming only the remaining files. Sources are still copied one at a time; no original is modified.

## Question and capability plan

Use `plan --request` to attach the supplied question to the selected material,
capabilities already available and authorized, and a step budget. Preserve
ambiguous input types until the question resolves them. A plan's case state can
surface conclusions needing review before new collection. Do not repeat intake
already established or treat a capability declaration as host permission.

## Resume a bounded plan

Use the existing case's review gaps and available inputs before proposing new
collection. Each ready action needs its required input and an available,
authorized capability. Preserve blocked/deferred actions, remaining action/time
budget and the recorded stop reason. The plan remains advisory. Optional host
parallelism uses independent tasks, minimized context and separate derived
outputs. A single coordinator appends case records after reviewing results.
